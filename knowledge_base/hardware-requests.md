# Hardware requests

Desk kit such as monitors, keyboards, and docks is issued by IT. Use this
page when something at your desk is missing or broken. It is not for
applications, time off, or guest access.

Replacement USB-C docks are ordered from the IT hardware catalog. Choose
desk delivery or locker pickup when you place the order. A personal dock is
not a substitute. Unapproved adapters often fail power delivery or dual
displays on company machines.

If a dock is damaged or missing, request a replacement rather than buying
one yourself. Return the broken unit in the same request so inventory stays
accurate. A full new-hire workstation is a different process; do not use
this path for an entire kit.

1. Open the IT hardware catalog and select the USB-C dock.
2. Choose desk delivery or locker pickup.
3. Record the asset tag of any dock you are sending back.

Do not leave an unknown dock plugged in overnight and assume it is safe.
Wait for the catalog item. If you only need a cable, order the cable from
the same catalog rather than borrowing unmarked accessories from an empty
desk.
